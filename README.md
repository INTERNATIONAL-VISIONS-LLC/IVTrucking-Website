Our mission is simple:

> Deliver freight with consistency, transparency, and professionalism while building long-term relationships with customers and drivers alike.

# 🌐 Platform Overview

The IVLLC website is designed as a modern logistics platform that combines freight information, recruiting, customer onboarding, and live visual experiences into a single responsive environment.

This production build includes:

- Animated cinematic homepage

- Interactive coverage experience

- Quote request pipeline
- Callback/contact forms
- FAQ and support system

# ⚙️ Deployment Notes

Upload the repository contents to a PHP-capable hosting environment.

Before launch:

1. Replace the placeholder Google Analytics ID:

```txt

```

2. Confirm PHP mail delivery for:

* `send_quote.php`
* `send_support.php`

3. Update:

* social media URLs
* sitemap domain
* production analytics
* SEO metadata

4. Test:

* mobile responsiveness
* quote forms
* recruiting links
* coverage iframe
* live tracker integration

5. Confirm all:

* assets
* overlays
* SVG references
* images
* navigation links
  work correctly on production hosting.
